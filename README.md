> 通过三项鼠标测试，分析你的操作习惯，生成可在**当前版本 PUBG**中直接使用的专属灵敏度配置。

## ✨ 简介

很多 PUBG 玩家在搜索引擎里抄来的灵敏度，并不适合自己——因为每个人的**鼠标 DPI、操作幅度、跟枪与甩枪习惯**都不同。

本项目是一个**纯前端、零依赖**的网页工具：你只需在浏览器里完成三项 10 秒小测试，工具就会根据你的真实操作数据，计算出一套包含 5 项数值（常规 / 垂直 / 瞄准 / 开镜 / 倍镜）的灵敏度方案，并给出**微调提升建议**与**预估 cm/360**。所有数值均落在 PUBG 设置允许范围内，可直接填入游戏。

### 为什么是这三项测试？

| 测试 | 测的是什么 | 生成时如何使用 |
|------|-----------|---------------|
| 🎯 追踪测试 | 跟枪稳定性（持续跟随移动目标） | 评估跟枪能力 → 影响常规/垂直灵敏度 |
| ⚡ 定位测试 | 甩枪与反应速度（快速命中随机目标） | 评估瞄准速度 → 影响瞄准/倍镜灵敏度 |
| 🔄 360° 转身测试 | 操作幅度（手腕型 vs 手臂型） | 推导常规灵敏度与预估 cm/360 |

## 🚀 功能特性

- **三项内嵌测试**，每项开始前 3 秒倒计时，鼠标移入即触发（无需点击）
- **点击「开始全部测试」**即可按顺序自动跑完三项，也支持**单项重测**
- **流畅的开始动画**：倒计时数字缩放淡入淡出、叠加层平滑过渡、等待鼠标的脉冲提示
- **DPI 校准**：不知道鼠标 DPI 也能用（用尺子量 10cm，指针锁定校准，全程在框内可见且准确）
- **五项灵敏度生成**：常规 / 垂直增强 / 瞄准 / 开镜模式 / 倍镜，均符合现版本 PUBG 设置范围
- **操作风格分析**：自动归类（全能突击 / 稳定跟枪 / 敏捷甩枪 / 稳健发育 / 均衡型）
- **性能分析**：追踪 / 定位 / 操作幅度 / 综合四项评分条
- **个性化微调建议**：基于测试结果给出 6 条可落地的提升建议
- **一键复制**：单个数值复制 + 一键复制全部配置
- **暗色游戏风 UI**：PUBG 金橙配色，响应式布局

## 🛠 本地运行

### 方式一：直接打开（最简单）
双击 `index.html` 用浏览器打开即可使用。

> ⚠️ 部分浏览器在 `file://` 协议下会限制 **Pointer Lock（指针锁定）**，导致 DPI 校准的「锁定光标」不生效。此时工具会自动回退到「自由移动」校准模式，仍可使用；或直接用方式二本地起服务以获得完整体验。

### 方式二：本地静态服务器（推荐）
```bash
# 进入项目目录
cd pubg-assistant

# 任选其一启动（需已安装 Python 或 Node）
python -m http.server 8137
# 或
npx serve .

# 浏览器访问
# http://127.0.0.1:8137/
```

## 📖 使用步骤

1. **设置 DPI**：选择你的鼠标 DPI；若不知道，点「校准我的 DPI」按提示用尺子量 10cm 校准。
2. **开始测试**：点「开始全部测试」顺序完成三项，或分别点每张卡片的「开始测试」。每项前 3 秒倒计时，鼠标移入测试框即开始 10 秒测试。
3. **生成灵敏度**：三项全部完成后「生成专属灵敏度」按钮亮起，点击生成配置。
4. **填入游戏**：将五项数值复制，进入 PUBG → 设置 → 鼠标灵敏度逐项填入。
5. **微调验证**：参考「微调提升建议」，在训练场逐步验证手感。

### 生成数值说明
- **常规灵敏度**（约 25–75）
- **垂直灵敏度增强**（约 0.70–1.30）
- **瞄准灵敏度**（约 25–75）
- **开镜模式灵敏度**（约 25–75）
- **倍镜灵敏度**（约 25–75，通常比开镜低几档）

> 数值基于当前版本 PUBG 设置范围推导，建议结合训练场实战手感做 ±2~3 点的微调。

## 🧮 算法简述

1. **360° 转身测试**的累计移动像素 → 结合 DPI 反推常规灵敏度与预估 `cm/360`；
   - 移动幅度大（手臂型）→ 常规灵敏度偏低；移动幅度小（手腕型）→ 偏高。
2. **追踪精准度**与**定位命中/反应**作为能力权重，对瞄准、倍镜、垂直灵敏度做比例微调；
3. 综合三项表现生成**操作风格标签**与**个性化建议**。

算法完全运行在浏览器本地，不上传任何数据，隐私安全。
